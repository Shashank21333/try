TubeScout extension settings

The extension shows data from your own TubeScout server on YouTube video, channel and search pages.

Where TubeScout runs (npm start prints it). localhost and 127.0.0.1 on any port work right away; any other address asks Chrome for permission to reach that host once.

Sent to your server as HTTP Basic auth. Stored only in this browser profile (chrome.storage.local), never synced, and never shared with YouTube pages.

What it uses

  • Video pages (/watch, /shorts): your server's /api/video. In live mode that costs a few YouTube Data API units per video (10,000 free units per day).
  • Channel pages: /api/channel, about 3–4 units per channel.
  • Search results: /api/demand, YouTube's public autocomplete (no API units). If your server has SerpAPI or Keywords Everywhere keys, the panel waits for a click because those cost credits.
  • Collapsed panels load nothing. Results are cached for 5 minutes per tab.

Permissions

  • storage: keeps the server URL, password and the collapsed/expanded state.
  • localhost, 127.0.0.1: lets the extension's background worker call a TubeScout server on this computer.
  • youtube.com: shows the panel on YouTube pages. The page itself never talks to your server; only the background worker does, and only to the TubeScout endpoints it needs.
  • Other hosts are optional and requested only for the server URL you save here.

Privacy

The extension talks only to the server URL above. It sends the video ID, channel or search term of the YouTube page you are viewing, nothing else. No analytics, no third parties.
