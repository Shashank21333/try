▶ TubeScout competitor & keyword research
Demo mode: channel and video numbers are synthetic (YouTube autocomplete ideas are real). Add YOUTUBE_API_KEY to .env and restart to analyze real channels.

Each keyword search uses 1 of your ~100 daily YouTube search calls plus ~2 of 10,000 daily units (cached 15 min). Search demand uses free YouTube autocomplete, plus Google Trends (2 SerpApi searches) and Keywords Everywhere (1 credit per keyword) when those keys are set.

TubeScout saves a snapshot of every tracked channel about once a day while the server is running (~3 API units per channel), so growth charts fill in over time.

Data from the YouTube Data API v3. Scores are transparent heuristics; see README for formulas.
